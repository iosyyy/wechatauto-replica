## 红转绿与审查

- 原包在没有 Windows 依赖的环境导入失败；延迟导入与原生 API 隔离后通过。
- Linux 账号歧义、目录穿越、Windows 回退、显式密钥被旧缓存覆盖、缓存权限，
  均先观察失败再修复。
- 规格审查发现输入密钥可与缓存输出路径冲突；修复为初始化前拒绝，原文件
  字节保持不变。
- 独立代码审查发现 `?` / `#` 路径会让 SQLite 校验打开错误文件；修复 Linux
  校验 URI，并增加 Linux 缓存版本以重建旧缓存。
- 独立代码审查发现 FIFO 可导致只读打开阻塞；修复为非阻塞打开后拒绝特殊文件。
- 修复后规格审查、代码审查均通过；不代表整个上游仓库已完成恶意代码排查。
